# 改稿包：展示網頁文案改寫用

[report.claire-cheng.com](https://report.claire-cheng.com/) 的網頁文字要改得更口語。這個資料夾把全文連同每段的事實根據匯出成一份稿件，交給 Antigravity 改寫。最高原則是**正確性**：改寫只能動措辭，不能改事實。

## 這裡有什麼

| 檔案 | 給誰 | 內容 |
|---|---|---|
| `改稿稿件.md` | 改稿者（Antigravity） | 網頁全文 185 段，每段分成「正文｜可改寫」和「事實卡｜不可改動」 |
| `改稿守則.md` | 改稿者（Antigravity） | 可以改什麼、不可以改什麼、術語表、Claire 的行文偏好 |
| `待裁決清單.md` | Claire | 網頁**現有**文字和資料或選項原文對不上的地方，以及每一項的裁決結果（2026-10-03 已全部裁決） |

改稿時把 `改稿稿件.md` 和 `改稿守則.md` 一起交給 Antigravity。`待裁決清單.md` 是給你看的，不用交出去。

## 流程

1. **（這一步）匯出改稿包**：產生上面三份檔案，並驗證稿件和網頁一字不差
2. ✅ **裁決 `待裁決清單.md`**（2026-10-03 完成）：要修的在 PR #22 修正網頁，保留原文的寫進事實卡，引號維持現狀的標成〔維持〕，再重新匯出
3. **Antigravity 改稿**：只改 `<!-- 正文開始 -->` 和 `<!-- 正文結束 -->` 之間的文字
4. **交回後檢查**（下一個 PR）：用程式逐段比對數字、檢查〔鎖〕引號沒被改，再逐段讀改寫內容、對照事實卡，抓新增的宣稱或悄悄變成因果的說法
5. **套回網頁**：`14_web_number_check.py` 全部通過、瀏覽器預覽確認版面，再走分支、PR、merge

## 怎麼重新產生

```bash
cd 04_問卷分析報告/分析程式
python3 15_copyedit_export.py
```

- `15_copyedit_export.py`：從 `docs/index.html`、`docs/data/figures.json`、`docs/js/app.js` 匯出全文，逐段核對數字並產生三份檔案
- `copyedit_facts.py`：每一段的事實對照表（數字來源、論點界線、已知問題）。**網頁文字有改，這份也要跟著改**，否則匯出時會因為數字清單對不上而失敗
- `16_copyedit_roundtrip.py`：拿瀏覽器實際顯示的文字和稿件比對（取得畫面文字的方法寫在腳本開頭）

⚠️ 有 6 個數字（2.1 的 42 位與 30 位、6.1 的 20／6／1 人、伍、反思的 26 人）只能從未公開的逐人明細 `分析結果/01_衍生變項.csv` 重算。沒有這份檔案時，匯出照常進行，但事實卡會註明「本次未重算」。
