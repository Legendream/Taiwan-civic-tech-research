## 〇、這個網頁要做什麼

把《公民科技生態系分析報告_定稿》做成一個**純靜態、可掛在自有網域**的互動網頁，
讓沒有下載 .docx 的人也能在瀏覽器裡讀完整份研究，並且每個數字都能當場看到分子與分母。

四個已定案的前提（2026-08-02 與 Claire 確認）：

| 項目 | 決定 |
|---|---|
| 內容範圍 | **全報告互動版**：背景、摘要、七章發現、建議、反思全部上網 |
| 圖表做法 | **用 `分析結果/` 的 CSV 重繪成互動 SVG**，不嵌入現成 PNG |
| 檔案位置與上線 | 本 repo 的 `docs/`，走 GitHub Pages，日後加 CNAME 綁自有網域 |
| 互動功能 | 四項全要：三群人分群切換、滑過顯示數字與分母、章節導覽與閱讀進度、依身分推薦讀哪一段 |

---

## 一、內容正確性（最高優先）

- [ ] **A1** 網頁上出現的每一個百分比與人數，都能在 `分析結果/99_數字索引.csv`
      或報告定稿 .md 中找到相同數值；由 `分析程式/14_web_number_check.py` 自動核對，
      對不上就讓腳本失敗。腳本輸出「網頁數字總數／核對通過數／未通過清單」。
- [ ] **A2** 15 張圖的**每一個數值**都由建置腳本從 `分析結果/*.csv` 讀出，
      不在 HTML 或 JS 裡手寫任何數字。圖表資料檔 `docs/data/figures.json` 由
      `分析程式/13_web_data.py` 產生，重跑會得到相同結果。
- [ ] **A3** 報告正文搬上網頁時，**不改動任何數字、結論或限制說明**。
      允許的改動只有：分段變短、加小標、把表格改成網頁表格。
      逐章比對報告定稿，確認沒有結論被弱化或加強。
- [ ] **A4** 每一張圖都標示**分母是誰**（例如「分母＝47 位曾參與者」），
      以及該題是不是複選。分母標示與報告定稿一致。
- [ ] **A5** 樣本限制不是只放在頁尾：`README.md` 裡那四條限制
      （取樣偏向已有興趣者、專案層級題只有 47 人、相關不是因果、困擾題沒有「沒遇到」選項）
      在網頁上有獨立區塊，且從導覽列到得了。
- [ ] **A6** 第五章「對立假設」六條全數呈現，不刪減。這是這份研究可被信任的部分，不是附錄。

## 二、互動功能（四項各自可驗）

- [ ] **B1 三群人分群切換**：凡是 `分析結果/` 有三層交叉資料的圖
      （活動意願、議題領域、跨領域工具、狩野落點），都能切換或並排比較
      「聽過或看過，還沒接觸／接觸過，還沒做過專案／做過專案」，
      切換後標題、分母、數值同步更新。三層固定配色沿用 `common.py` 的
      `PALETTE["layers"]`（綠／橘／藍），色隨身分固定，不隨排序改變。
- [ ] **B2 滑過顯示數字與分母**：滑鼠移到任一資料點，顯示「選項名稱、比例、分子/分母」。
      **手機沒有滑鼠**，所以數值必須同時直接標在圖上，不是只有 hover 才看得到。
- [ ] **B3 章節導覽與閱讀進度**：側邊（手機為收合選單）有全篇章節目錄，
      捲動時高亮目前章節，點擊可跳轉，每個章節有可複製的錨點網址。
- [ ] **B4 依身分推薦讀哪一段**：讀者可選「我是新手／我在做專案／我可能出資源或經營社群」，
      選完後頁面標出建議閱讀的章節。三條路線的選章依據寫在頁面上，不是憑感覺挑的。
      不選也能正常讀完全文，這個功能是加分不是關卡。

## 三、可讀性與相容性

- [ ] **C1** 手機（寬 375px）上：不出現橫向捲動、文字不小於 15px、
      圖表自動換成適合窄螢幕的版面，圖上的數值標籤讀得到。
- [ ] **C2** 桌機（寬 1280px）上：內文區塊有最大寬度，不會拉成一整行難讀的長句。
- [ ] **C3** 每張圖下方有「看數據表」可展開，內容即該圖的來源 CSV 數值。
      這同時是色彩對比的補償措施（`common.py` 註記調色盤對比為 WARN，
      依 relief rule 一律附直接數值標籤與數據表）。
- [ ] **C4** 圖表用 SVG 而非 canvas，文字可被選取、可被搜尋、可被螢幕閱讀器讀到；
      每張圖有 `<title>`／`aria-label` 說明它在講什麼。
- [ ] **C5** 深色模式下可讀（跟隨系統設定），或明確只做淺色但不會在深色瀏覽器下破版。

## 四、靜態與可部署

- [ ] **D1 零外部請求**：不連任何 CDN、字型服務、統計服務、追蹤碼。
      斷網開啟 `docs/index.html` 仍完整可讀。以瀏覽器 Network 面板驗證外部請求數為 0。
- [ ] **D2 零建置步驟**：不需要 npm、不需要打包工具。把 `docs/` 整包丟到任何靜態主機即可跑。
- [ ] **D3** `docs/` 內含 `.nojekyll`，避免 GitHub Pages 的 Jekyll 處理掉檔案。
- [ ] **D4** 綁自有網域的步驟寫在 `docs/README.md`：要在 GitHub 開哪個設定、
      CNAME 檔怎麼放、DNS 要指到哪。**我不代你按 GitHub 設定**，文件寫清楚讓你自己開。
- [ ] **D5** 所有路徑為相對路徑，網站放在網域根目錄或子目錄都能正常運作。

## 五、個資與授權

- [ ] **E1** 網頁只使用**彙總層級**的數字，不出現任何逐人資料、開放題原文、
      組織名稱或專案名稱。比照 `.gitignore` 的判斷原則：可識別到填答者的一律不上網。
- [ ] **E2** 開放題的呈現只到「主題 × 人數」的次數表（來源 `09_開放題_*.csv` 的彙總欄位），
      不引用任何一句填答者原話。
- [ ] **E3** 頁尾標示授權 `CC BY 4.0, by g0v.tw jothon & Claire Cheng`、作者、資料範圍
      （截至 2026/7/20、127 份），並連回 GitHub repo 讓人可核對數字。
- [ ] **E4** 網頁不嵌入 `01_文獻與桌面研究/` 那三篇論文的任何圖或表
      （著作權不屬於本專案，先前已查證不可隨 CC BY 發布）。

## 六、可維護

- [ ] **F1** 日後問卷樣本增加時，重跑 `13_web_data.py` 就能更新網頁上所有圖表數值，
      不必手改 HTML。這一條在 `docs/README.md` 寫明操作方式。
- [ ] **F2** 新增的兩支腳本（`13_web_data.py`、`14_web_number_check.py`）
      沿用 `common.py` 的路徑與配色常數，不另外定義一份。

## 站③自我驗證方式

- A1、A2、F2：跑 `python3 13_web_data.py && python3 14_web_number_check.py`，貼出輸出。
- A3～A6、E1～E4：逐章對照報告定稿，列出對照結果。
- B1～B4、C1～C5、D1：用瀏覽器實際操作（含 375px 與 1280px 兩種寬度），逐條記錄。
- D2、D5：在乾淨資料夾以 `python3 -m http.server` 開啟，確認可跑。
