# 臺灣公民科技參與者需求調查

g0v 揪松團委託的「臺灣公民科技專案與工具行動指引」案，第一階段的問卷研究。
這個 repo 放**研究方法、分析程式與分析結果**，讓報告裡的每個數字都可以被別人重算與質疑。

- 問卷回收至 2026/7/20，有效樣本 **127 份**
- 分析：鄭婷宇（Claire）
- **報告定稿**：[`04_問卷分析報告/`](04_問卷分析報告/)——`.docx` 是交付甲方的排版版本，`.md` 是供程式稽核的正本
- **互動網頁**：[`docs/`](docs/)——同一份報告的網頁版，GitHub Pages 部署方式見 [`docs/README.md`](docs/README.md)

## 這裡沒有填答者的原始資料

`03_問卷回收資料/` 不在版控裡，這是刻意的。問卷對填答者的承諾是**全程匿名**，而去識別化不等於可以公開發布——移除 email 與電話之後，「組織名稱 ＋ 專案描述 ＋ 專案階段 ＋ 困擾評分」的組合在台灣公民科技這個小社群裡仍可能指認到人。

同理，逐人層級的衍生檔（`01_衍生變項.csv`、`10_逐人核對表.csv`）與開放題原文（`09_開放題_編碼對照.csv`）也不在版控裡。

**可公開的原始資料由 g0v 揪松團自己發布。** 取得後放進 `03_問卷回收資料/`，依 `分析程式/common.py` 的 `CLEAN_CSV` 路徑命名，即可從 `00_clean.py` 開始重跑整條 pipeline。

## 怎麼重跑

```bash
cd 04_問卷分析報告/分析程式
python3 00_clean.py && python3 01_indices.py && python3 02_kano.py && python3 03_crosstab.py
python3 04_motivation.py && python3 05_figures.py && python3 09_opentext.py && python3 10_role_crosstab.py
python3 11_activity_by_layer.py
python3 06_number_index.py   # 回頭稽核報告本文的每一個百分比
python3 12_source_audit.py   # 逐處列出報告每個數字取自哪一題、分母是誰
python3 13_web_data.py       # 產生 docs/ 展示網頁用的資料檔
python3 14_web_number_check.py  # 稽核展示網頁上的每一個百分比
```

需要 Python 3、pandas、numpy、scipy、matplotlib。

`06_number_index.py` 會掃報告本文裡每一處「百分比（分子/分母）」並重算，對不上就讓腳本失敗——這是防止數字漂移的機制。

## 讀這些資料前要知道的限制

- 問卷透過 g0v 及相關社群管道發放，樣本偏向「已對公民科技有興趣的人」，結論只能推論到本次受訪者，不代表全體大眾。
- 全體 127 人回答的題目結果相對穩定；但**專案層級的題目**（階段、資源、困擾、動機）只有做過專案的 47 人回答，再往下細分每組只剩十幾人，只能當作值得再驗證的方向。
- 所有交叉都是相關，不是因果。
- 困擾題實際上線的版本沒有「沒遇到」選項，平均分系統性低估，主要指標一律用「3 分以上（3＋4＋5 分合計）」。
- 完整的限制與「這份資料不能說什麼」寫在報告第 10–11 章。

各 CSV 內都附有 `信賴度`、`決策可用性` 與 `讀法說明` 欄位，單獨取用某一張表時請一併閱讀。
