# 07_成果推廣

**簡報是 [`工作坊簡報.html`](工作坊簡報.html)**（22 頁）。用瀏覽器直接打開就能播放，講稿也寫在這個檔案裡。

合約階段 5「成果推廣」的工作區：公民科技工作坊的錄影演講簡報。

## 講者視窗（看講稿用）

在簡報按 `S`，或移動滑鼠後點控制條上的「講稿」，會開出另一個視窗，顯示目前這一頁的講稿、下一頁的標題與計時器。簡報畫面本身不會出現講稿。

- 兩個視窗會連動：簡報換頁，講稿跟著換；在講者視窗按 ← → 也能替簡報換頁。
- 計時器在第一次換頁時自動開始；也可以按 `T` 或點按鈕手動開始、暫停，按 `R` 歸零。
- 講者視窗的按鍵：← → 換頁、`T` 開始或暫停計時、`R` 歸零、`+` `-` 調整字級。字母鍵在中文輸入法開著時也有效。
- 錄影建議（雙螢幕）：簡報放在要錄的螢幕並按 `F` 全螢幕；講者視窗拖到另一個螢幕。錄影時把滑鼠留在講者視窗操作，游標就不會出現在錄影畫面上。
- 沒有連動對象時也能用：直接開 `工作坊簡報.html?speaker`，就是可以自己翻頁的講稿（例如放在平板上）。
