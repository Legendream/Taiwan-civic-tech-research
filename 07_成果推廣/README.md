# 07_成果推廣

**簡報是 [`工作坊簡報.html`](工作坊簡報.html)**（22 頁）。用瀏覽器直接打開就能播放，講稿也寫在這個檔案裡。

合約階段 5「成果推廣」的工作區：公民科技工作坊的錄影演講簡報。

## 資料夾

| 位置 | 放什麼 |
|---|---|
| `工作坊簡報.html` | 簡報本體，也是原始檔，要改簡報就改這個檔 |
| `assets/` | 簡報實際用到的圖片、標誌、QR code；`assets/charts/` 是圖表的 SVG 原檔 |
| `tools/make_charts.py` | 從 `docs/data/figures.json` 重畫圖表，輸出到 `assets/charts/` |
| `文件/` | 現行的工作文件 |
| `封存/` | 已被取代的舊版，留著備查，不再更新 |

## 文件/

| 檔案 | 用途 |
|---|---|
| `簡報排版修正_驗收與刪減對照.md` | 每一輪修改的驗收結果、文字替換對照、待確認事項。接續精修時先讀第六節 |
| `工作坊簡報_訪談筆記與論述脈絡.md` | 講者訪談筆記、論述脈絡與文獻依據 |

| 檔案 | 說明 |
